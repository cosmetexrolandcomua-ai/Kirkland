# Комплекти для схем лікування

Нові комплекти побудовані за доказовими схемами (AAD 2024 з акне, European S3, стандарти терапії псоріазу, розацеа, мелазми та рубців).
Кожен компонент звірено з `kirkland_asortyment.xlsx.xlsx`: усі позиції **In Stock**. Готові комплекти магазину (Perolite, Eleneon, Tarlic, Експігмент + Kojivit) тут не повторюються.

- `komplekty_likuvannya.xlsx` — аркуш «Комплекти» (назва, склад, ціни, схема, пояснення, застереження) та аркуш «Склад» (product_id, URL).
- `build_kits.py` — генератор. Ціна комплекту = сума поточних цін (з урахуванням акційних) − 10%, округлена до ...9.

## Ключові принципи
- **BPO поєднано з адапаленом/трифаротеном, а не з третиноїном**: бензоїл пероксид окислює третиноїн при одночасному нанесенні.
- **Кліндаміцин лише разом з BPO**: так бактерії не набувають резистентності (вимога AAD).
- **Cutacnyl 10% — тільки для тіла**: на обличчі 2.5% так само ефективний, але подразнює менше.
- Комплекти з гормональними/рецептурними засобами (Псоркутан Бета, Triluma, кліндаміцин) у картці мають містити рекомендацію консультації дерматолога.

## Прогалини асортименту
Для повних схем бракує: івермектин 1% (Soolantra) для розацеа, міноксидил для алопеції, бальзам для губ (курс ізотретиноїну), недорогий SPF 50 (зараз лише Dr.Richesse за 2021 грн).
